## 1. What each filled file does

| File(s) | Why it exists |
|---|---|
| `pyproject.toml` (root) | uv **workspace**: one lockfile for 5 packages. Also holds config for ruff, mypy, pytest, coverage, import-linter. |
| `packages/*/pyproject.toml`, `apps/*/pyproject.toml` | Each package's name and dependencies (`cocok-adapters` depends on `cocok-core`, …). |
| `uv.lock` (generated) | Exact versions of every library → same result on your Mac, CI and the server. |
| `.python-version` | Python 3.13; uv downloads it automatically. |
| `Makefile` | Short commands: `make setup`, `make lint`, `make type`, `make test`, `make gate CP=01`. |
| `scripts/gates/_lib.sh`, `cp00.sh`, `cp01.sh` | One command per checkpoint; every `step` prints ✔ or ✘ so you see exactly which rule broke. |
| `.pre-commit-config.yaml` | The same checks run before every `git commit` (incl. gitleaks for secrets). |
| `.github/workflows/*.yml` | CI on GitHub: lint/types/tests, security scans, checkpoint gates. Actions pinned to commit SHAs (ADR-0011). |
| `conftest.py` | Hypothesis profiles: `dev` (fast) and `ci` (500 examples). |
| `*/src/*/__init__.py` + `py.typed` | Makes each folder an importable, typed package. |
| `*/tests/test_smoke.py` | Proves each package imports (marker `cp01`). |

**The most important idea — import-linter contracts** (bottom of root `pyproject.toml`): the architecture you drew
(core ← adapters ← apps; ml separate) is *enforced by a test*. If someone imports the database inside `core`,
`make lint` fails.

## 2. Run it on your Mac
```bash
cd monorepo-cv2-project
make setup                              # installs Python 3.13 + all tools, installs git hooks
make gates-upto CP=01                   # expect GATE cp00: PASS and GATE cp01: PASS
uv run pre-commit run --all-files       # first run downloads hooks incl. gitleaks
git log --oneline                       # 2 commits: your architecture, then CP-01
git show --stat HEAD                    # which files CP-01 filled
```
